## GitHub Pages
Upload ketiga file tersebut langsung ke ROOT repository:
repository/
  index.html
  style.css
  script.js

Jangan masukkan ketiganya ke dalam subfolder jika menggunakan `/ (root)` sebagai Pages source.

Settings → Pages → Deploy from a branch → main → /(root) → Save.
